# Stay on task. Ship with confidence.

Context Guard keeps your agent focused on the current goal of work and nudges it back only when context drifts—so long sessions stay aligned with what you actually asked for.

## Features

- **Pinned current goal** — Name the chunk you’re working on; it stays in front of the model until you move on.
- **Drift-aware redirects** — Get a gentle redirect when the conversation abandons that unit, not on every tangent.
- **Quality gate before done** — Run a built-in check so “finished” means verified, not just declared.
